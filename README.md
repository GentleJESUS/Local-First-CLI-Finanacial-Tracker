# Local-First-CLI-Finanacial-Tracker
Fast, privacy-focused command-line tool for personal finances. Track income, expenses, and budgets entirely offline with zero cloud sync or telemetry.

# Overview
The Local-First CLI Financial Tracker is designed for power users and privacy advocates who want absolute ownership over their financial data. Built for speed and security, it allows you to track income, categorize expenses, monitor budgets, and generate deep financial insights directly from your terminal—without relying on third-party SaaS platforms or exposing sensitive banking data to the cloud.Key 

# FeaturesAbsolute Privacy: 
Stored locally in an encrypted database. No accounts, no cloud syncs, and zero telemetry.Fast CLI Workflow: Keyboard-driven navigation, autocomplete, and a minimal resource footprint.

# Terminal Analytics: 
Render ASCII charts, spending distributions, and cash-flow trends directly inside your shell.

Flexible Import/Export: Import CSVs from major banks and export data anytime in JSON, CSV, or Markdown.

Smart Rules & Budgets: Auto-categorize transactions using regex patterns and set visual spending alerts for category limits.
